# muesli

Easily export your data from Granola.


> [!WARNING]
> This tool currently only works on macOS!

> [!NOTE]
> Requires Deno! E.g.
>
> ```shell
> brew install deno
> ```

```shell
git clone https://github.com/montyanderson/muesli.git
cd muesli
```

```shell
./muesli
```
